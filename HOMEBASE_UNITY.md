HeritageFaith and the Home Base workbench are now one private single-user Android source tree.

## Private library
Six Google Drive folder locations are registered as source shelves. Because Android and Google Drive
require user authorization, the source package does not contain the book bytes. The Library page now
supports multi-file selection through Android's document picker; choosing Google Drive there copies
selected books into app-private managed storage, hashes them, and records provenance.

## Ademic Cantus

Cantus Logs remain the append-only evidence chain for native mutations.

## Continuity
The Android application ID remains `com.arkforge.faith` to preserve upgrade/data continuity.
No prior source is silently deleted or overwritten.
