# HeritageFaith — Public / Private Separation

## Public: HeritageFaith
Scripture-first retail application, clean local database, public study datasets, generic feature templates, customer-created local records.

## Private: Home Base / development archives
Owner-specific projects, continuity exports, private books/scans, personal files, private genealogy, medical/contact/location data, experimental private systems, and historical development artifacts.

Private source/history that must be retained for continuity is stored outside the compiled public source tree under `legacy_private_reference/`. Historical public assets removed from runtime are stored under `legacy_public_reference/`. Preservation does not imply retail inclusion.
