## Red-letter truth boundary
V16 does not pretend a verse-level reference index can safely recolor every phrase spoken by Jesus. Existing red-letter marks remain reversible, source-tracked annotations. Phrase-level red-letter data still needs a reviewed source aligned to the Douay-Rheims wording/verse numbering before it is promoted as complete.
