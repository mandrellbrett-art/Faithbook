# HeritageFaith — Scripture Context Atlas

The Scripture Context Atlas surrounds Scripture with clearly labeled research without editing the source text.

It organizes names, languages, people, peoples, places, objects, maps, timelines, foodways, plants, animals, materials, Church roles, traditions, and source-labeled commentary.

## Seven Commentary Leaves
1. Text + Translation
2. Names + Language
3. People + Peoples + Relationships
4. Places + Maps + Environment
5. Objects + Institutions + Daily Life
6. Timeline + Historical Setting
7. Theology + Interpretations + Resolution

Uncertainty and disagreement remain visible. Scripture, Church teaching, history, scholarship, study commentary, and personal notes are never silently blended.
